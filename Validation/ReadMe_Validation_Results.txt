The results from the validation run at Re=200 were 0.194 for the Strouhal number and 0.64 for the maximum coefficient of lift. This is a 1.5% and 7.2% error respectively compared to the published data of Williamson (1989), where the Strouhal number was determined to be 0.197 and the maximum coefficient of lift was 0.69. These results confirm that the meshing methodology produces physically valid results. A small increase in mesh refinement is expected to improve accuracy further, which will be quantified in the mesh independence study.
